01_ 核心概念：二次函數與拋物線頂點

二次函數在坐標平面上的圖形是一條「拋物線」。拋物線最重要的幾何特徵在於開口方向與極值點（頂點）。

  • 開口方向 (a)： \( a > 0 \) 時開口向上（存在最小值）；\( a < 0 \) 時開口向下（存在最大值）。
  • 頂點式形態： 標準式為 \( y = a(x - h)^2 + k \)，其頂點坐標直接可讀出為 \((h, k)\)。
  • 對稱軸： 直線 \( x = h \) 為拋物線的左右對稱軸。

03_ 統測重點：一般式配方與極值應用

高職數學 C 必考三大重點公式

  • 一般式轉換配方法：\( y = ax^2 + bx + c \)
    利用配方法改寫為頂點式：頂點 \( x \) 坐標為 \( x = -\frac{b}{2a} \)。

  • 極值公式：
    當 \( a > 0 \)，在 \( x = -\frac{b}{2a} \) 處有最小值 \( \frac{4ac - b^2}{4a} \)；
    當 \( a < 0 \)，在 \( x = -\frac{b}{2a} \) 處有最大值。

  • 判別式與 x 軸交點：\( D = b^2 - 4ac \)
    \( D > 0 \) 相交兩點；\( D = 0 \) 相切一點（頂點在 x 軸上）；\( D < 0 \) 浮空無交點。

極值求解範例

若雲霄飛車的軌道高度可以用二次函數表示：

f(x) = -x² + 6x + 10

配方後：
f(x) = -(x - 3)² + 19

➔ 當 x = 3 時，軌道達到最高點 19 米。
